# COVO Validator: Student Experiment

Welcome! In this assignment, you will design a Business Architecture using ArchiMate and validate it using the COVO Validator.

## Your Task

Model the provided case study. Your model must include one or more value streams, capabilities, and business objects.

### Step 1: Build the Initial Model

1. Model your case in Archi.
2. **Important:** *Do not use the COVO Validator yet!*
3. Save your model as `CaseName_Draft.archimate`.

### Step 2: The First Audit

1. Install the COVO Validator (see instructions in the main [README](https://github.com/sefanja/COVO-Validator)).
2. Run the tool on your entire model in **Audit** mode.
3. **Save your Results:**
   In the Archi Script Console, select all text (`Ctrl+A`), copy it (`Ctrl+C`), and **save it in a text file** (e.g., Notepad) or keep it on your clipboard. You will need to paste this entire console output into the evaluation survey later.

## Step 3: Fix and Pass

1. Read the advice given by the validator in the console.
2. Fix the errors in your model. You can run the tool in **Construction** Mode as often as you like during this process.
3. Continue until the tool in **Audit** mode reports `OVERALL STATUS: PASSED`.
4. Save your final model as `CaseName_Final.archimate`.

## Final Step: Submit your results

Please fill out the evaluation survey and upload your two ArchiMate files (`Draft` and `Final`). You will also be asked to paste the console output from Step 2.
